# License Attributions — Illustration & Media Assets

This file logs the source and license of EVERY external illustration or
media asset used anywhere in VeriTriage. If an asset is not logged here,
it must not be shipped.

## Currently used assets

**None.** As of Stage 4, all diagrams in the explanation layer are
generated programmatically as SVG by `backend/explanations/diagram_generator.py`
(no external images, no anatomy artwork, no adapted textbook figures).

## Pre-approved sources (for future assets)

If an illustration asset is ever needed, it may ONLY be sourced from the
following, and must be logged in the table below before use:

| Source | License | Notes |
|---|---|---|
| OpenStax Anatomy & Physiology | CC-BY | Attribution required |
| Wikimedia Commons | Varies — verify the individual file's license (CC-BY / CC-BY-SA) per file before use | Per-file license check is mandatory; log the specific license found |
| NCI Visuals Online | Public domain | Confirm the individual item is marked public domain |
| Servier Medical Art | CC-BY (attribution required) | Attribution must name Servier Medical Art |

Anatomy textbook images (scanned, embedded, or adapted) are NOT permitted
from any source.
